# CodeAlpha Hangman Game

A simple text-based Hangman game developed using Python.

## Features

- 5 predefined words
- Random word selection
- Maximum 6 incorrect guesses
- Console-based gameplay
- Input validation

## Technologies Used

- Python
- Random module

## How to Run

Run the following command:

python hangman.py
